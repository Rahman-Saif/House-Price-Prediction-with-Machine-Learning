## 📌 Project Overview
This project is a Machine Learning-based House Price Prediction system that estimates property prices based on various features such as location, size, number of rooms, area type, and other housing characteristics.

Live Demo : https://def87a9db1e0949799.gradio.live/
<img width="1912" height="680" alt="image" src="https://github.com/user-attachments/assets/e4291dc0-5aa5-4b0d-b246-38cb1cd0110d" />


The main goal of this project is to build a regression model that can predict house prices accurately and help understand the key factors that influence real estate pricing.

---

## 🚀 Problem Statement
House prices depend on multiple factors including location, area, and property features. This project aims to analyze these factors and build a predictive model that can estimate house prices effectively.

---

## 📂 Dataset Information

The dataset includes features such as:

- area_type
- availability
- location
- size
- society
- total_sqft
- bath
- balcony	price


---

## 🧹 Data Preprocessing

The following preprocessing steps were performed:

- Handled missing values  
- Removed outliers  
- Encoded categorical variables  
- Feature engineering  
- Data normalization / scaling  

---

## 🤖 Machine Learning Models

The following regression models were tested:

- Linear Regression  
- Decision Tree Regressor  
- Random Forest Regressor  
- Gradient Boosting Regressor  

### 📌 Final Model:
The best-performing model was selected based on evaluation metrics.

---

## 📊 Evaluation Metrics

- R² Score  
- Mean Absolute Error (MAE)  
- Mean Squared Error (MSE)
